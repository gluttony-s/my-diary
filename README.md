# Мой Дневник

Небольшой PWA-дневник без сервера: данные сохраняются в `localStorage` браузера.

## Что доработано

- Адаптация для ПК: приложение теперь использует широкое окно и раскладывает заметки, задачи и фотографии по колонкам.
- «Умный поиск»: при вводе текста, например `Т`, сразу показываются подходящие **подтемы и задачи**.
- Записи выбираются прямо в списке нажатием на строку.
- После выбора существующего JSON каждая запись получает статус **«В файле»** или **«Нет в файле»**.
- **«Добавить выбранное в файл»** добавляет только выбранные записи, которых нет в целевом JSON.
- **«Скачать выбранное»** создаёт отдельный JSON только из выбранных записей.
- Обновлена версия service worker, чтобы браузер после обновления приложения не использовал старый интерфейс из кэша.

## Структура

- `index.html` — разметка приложения.
- `style.css` — стили и адаптация под ПК/телефон.
- `app.js` — логика дневника и поиска.
- `manifest.json` — настройки PWA.
- `sw.js` — офлайн-кэш.
- `icon.png` — иконка.
- `README.md` — описание.

## Данные

Записи хранятся локально в браузере. GitHub хранит код приложения, но не содержимое вашего `localStorage`.

Для переноса данных между устройствами используйте встроенный экспорт/импорт JSON.
