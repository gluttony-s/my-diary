# Мой Дневник

Небольшой PWA-дневник без сервера: данные сохраняются в `localStorage` браузера.

## Что умеет

- Дневник по дням: заметка, настроение, подтемы, задачи, фотографии.
- 🌐 **Глобальные записи** — подтемы и задачи, не привязанные к конкретному дню.
- ⏰ **Будильники** к задачам (срабатывают один раз в сутки).
- 🗂️ **Умный поиск** по всем записям (включая глобальные):
  - фильтр по диапазону дат;
  - фильтр по типу: **Все / Только темы / Только задачи**;
  - статус каждой записи: **«В файле»** или **«Новая»**;
  - выбор записей галочками.
- 📥 **Экспорт и импорт**:
  - `📥` — скачать весь дневник;
  - `🗂️` — выборочный экспорт и слияние с существующим JSON
    (внутри можно ограничить выбор только темами или только задачами через фильтр «Тип»);
  - `📤` — загрузить бэкап.
- 🧭 **Навигация по неделям** — при перелистывании недели автоматически выбирается понедельник.

## Структура

- `index.html` — разметка приложения.
- `style.css` — стили и адаптация под ПК/телефон.
- `app.js` — логика дневника и поиска.
- `manifest.json` — настройки PWA.
- `sw.js` — офлайн-кэш.
- `icon.png` — иконка.
- `README.md` — описание.

## Данные

Записи хранятся локально в браузере. GitHub хранит код приложения, но не содержимое вашего `localStorage`.

Для переноса данных между устройствами используйте встроенный экспорт/импорт JSON.
